> 状态：甲方评审稿

## 一、项目概述

### 1.1 项目背景

近年来，我国儿童青少年近视率居高不下，已成为影响国民健康的重大公共卫生问题。为贯彻落实《综合防控儿童青少年近视实施方案》和《"十四五"全国眼健康规划（2021-2025年）》，建设一套覆盖国家-省-市-县-校五级的视力电子档案可视化平台，实现视力健康数据的采集、存储、分析和可视化展示，为近视防控工作提供科学数据支撑。

### 1.2 建设目标

1. **数据采集规范化**：建立标准化的视力筛查数据采集流程，支持批量导入与在线录入
2. **数据管理一体化**：构建学生视力电子档案，实现视力变化全程追踪
3. **数据可视化直观化**：开发多层级数据可视化看板，支持PC、平板、大屏等多终端展示
4. **权限管理精细化**：实现基于组织层级的分级授权与数据隔离
5. **分析决策科学化**：提供多维度统计分析报表，支撑近视防控决策

### 1.3 适用范围

| 层级 | 适用部门 | 主要功能 |
|------|----------|----------|
| 国家级 | 教育部、卫健委 | 全国数据总览、政策制定 |
| 省级 | 省教育厅、卫健委 | 省级数据看板、区域对比 |
| 市级 | 市教育局、卫健委 | 市级数据看板、考核排名 |
| 县级 | 县教育局、卫健委 | 县级数据看板、重点关注 |
| 校级 | 学校、卫生院 | 学校看板、个案追踪 |

## 二、系统架构

### 2.1 总体架构

```
┌─────────────────────────────────────────────────────────────┐
│                      用户层 (多终端适配)                        │
│    PC浏览器 │ 平板设备 │ 大屏展示 │ 移动端                      │
├─────────────────────────────────────────────────────────────┤
│                      展示层 (Vue 3 + Ant Design Vue)        │
│  全国大屏 │ 省级看板 │ 市级看板 │ 县级看板 │ 学校看板            │
├─────────────────────────────────────────────────────────────┤
│                      业务层 (Vue 3 + TypeScript)             │
│  学生档案 │ 数据采集 │ 统计分析 │ 报表管理 │ 系统管理           │
├─────────────────────────────────────────────────────────────┤
│                      数据层 (RESTful API)                   │

├─────────────────────────────────────────────────────────────┤
```

## 三、功能模块设计

### 3.1 前端可视化核心模块

#### 3.1.1 全国总览大屏

**功能描述**：展示全国中小学视力健康数据整体情况，为国家层面决策提供数据支撑。

**核心指标卡片**：
- 累计建档学生数
- 本年度筛查次数
- 视力异常人数
- 平均视力不良率

**可视化图表**：
| 图表类型 | 展示内容 |
|----------|----------|
| 折线图 | 全国视力不良率月度趋势 |
| 饼图 | 各省视力不良率分布 |
| 柱状图 | 各年级视力对比 |
| 仪表盘 | 年度目标达标情况 |
| 地图 | 全国各省份视力状况热力图 |

**快速入口**：
- 省级看板跳转
- 市级看板跳转
- 学生档案管理
- 数据采集入口

#### 3.1.2 省级可视化看板

**功能描述**：展示本省各地市视力数据，支持各地市横向对比。

**核心功能**：
- 地市排名列表（视力不良率从高到低排序）
- 各地市数据钻取
- 月度/季度趋势分析
- 预警学校标识

#### 3.1.3 市级可视化看板

**功能描述**：展示本地市各区县视力数据，支持区县横向对比。

**核心功能**：
- 区县排名列表
- 学校抽查数据展示
- 预警学生分布

#### 3.1.4 学校可视化看板

**功能描述**：展示本校学生视力健康状况，支持班级对比和学生追踪。

**核心功能**：
- 各班级视力不良率排名
- 学生视力变化追踪曲线
- 重点关注学生名单
- 年度筛查进度

#### 3.1.5 核心可视化图表库

| 图表类型 | 适用场景 | 交互特性 |
|----------|----------|----------|
| 折线图 | 趋势展示 | 支持缩放、数据点提示 |
| 柱状图 | 对比分析 | 支持堆叠、分组 |
| 饼图 | 占比分析 | 支持环形、玫瑰图 |
| 仪表盘 | 目标达成 | 支持多指针 |
| 地图 | 区域分布 | 支持下钻、热力 |
| 散点图 | 分布分析 | 支持回归线 |

### 3.2 后端核心功能模块

#### 3.2.1 学生电子档案管理

**功能概述**：建立和管理学生视力电子档案，实现"一人一档、档随人走"。

**核心字段**：
| 字段类别 | 字段名称 | 说明 |
|----------|----------|------|
| 基本信息 | 学号、姓名、性别、出生日期 | 身份标识 |
| 学校信息 | 学校、年级、班级 | 归属机构 |
| 视力数据 | 左/右眼视力、矫正视力、屈光度 | 筛查记录 |
| 预警信息 | 预警等级、关注状态 | 重点标识 |
| 档案状态 | 建档状态、更新时间 | 状态管理 |

**核心功能**：
- 新增/编辑/删除学生档案
- 批量导入学生档案（Excel）
- 导出学生档案（Excel/PDF）
- 档案查询与筛选
- 视力变化追踪

#### 3.2.2 数据采集与审核

**功能概述**：支持多种方式采集视力筛查数据，并经过审核流程确保数据质量。

**数据采集方式**：
1. **Excel批量导入**
   - 支持标准模板下载
   - 数据格式校验
   - 错误数据定位与修正
   - 导入进度展示

2. **在线单条录入**
   - 扫码快速定位学生
   - 表单校验与智能提示
   - 快速保存与继续

**审核流程**：
```
数据导入 → 格式校验 → 数据预览 → 提交审核 → 审核通过 → 数据入库
                                  ↓
                            审核驳回 → 数据修正 → 重新提交
```

**审核功能**：
- 待审核数据列表
- 批量审核/逐条审核
- 驳回原因填写
- 审核记录追溯

#### 3.2.3 统计分析与报表生成

**统计分析维度**：

| 分析维度 | 统计指标 |
|----------|----------|
| 时间维度 | 月度/季度/年度趋势、同比/环比 |
| 空间维度 | 全国/省/市/县/校分级统计 |
| 机构维度 | 学校类型对比、公办/民办对比 |
| 人群维度 | 年级对比、性别对比、年龄段对比 |
| 指标维度 | 视力不良率、近视率、高度近视占比 |

**报表类型**：
| 报表类型 | 生成周期 | 主要用途 |
|----------|----------|----------|
| 视力筛查汇总表 | 月度/季度 | 数据统计上报 |
| 视力不良率分析表 | 季度/年度 | 趋势分析 |
| 重点关注学生清单 | 周度 | 跟踪干预 |
| 学校年度视力报告 | 年度 | 综合评估 |
| 区域对比分析表 | 季度 | 横向对比 |

**导出格式**：PDF、Excel、Word

#### 3.2.4 系统管理模块

**用户管理**：
- 用户增删改查
- 批量导入用户
- 分配用户角色
- 重置用户密码

**角色管理**：

| 县级管理员 | 县 | 本县数据 |
| 校级管理员 | 校 | 本校数据 |

**权限管理**：
- 菜单权限

**组织管理**：
- 五级组织架构维护

- 组织关系树展示
- 组织数据关联

**字典管理**：

**操作日志**：

## 四、数据安全设计

### 4.1 分级数据隔离

| 用户角色 | 可访问数据范围 |
|----------|----------------|
| 超级管理员 | 全国数据 |
| 省级管理员 | 本省及下级数据 |
| 市级管理员 | 本市及下级数据 |
| 县级管理员 | 本县及下级数据 |
| 校级管理员 | 本校数据 |

### 4.2 数据权限控制

- 行级数据权限：根据用户所属机构过滤数据
- 列级数据权限：根据用户角色控制敏感字段可见性
- API级权限：接口访问需携带有效Token

### 4.3 安全措施

- 敏感数据加密存储
- 密码加密传输（HTTPS）
- 登录失败锁定
- 操作日志全记录
- 定期数据备份
